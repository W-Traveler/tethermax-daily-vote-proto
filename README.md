# TetherMax 비트코인 방향 맞추기 · 개발 확인용 프로토타입

Figma 기획서(Bitcoin direction call · KO)와 PRD 기준으로 화면 케이스를 하나씩 열어 확인하는 프로토타입입니다.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 상단 막대 | 버전 배지, KO / EN 전환, 설명 번호 표시, [화면 설명] 패널 |
| 화면 · 상태 설정 | 화면 묶음 · 케이스, 상태값, 사용자 폭(창 폭 · 1440 · 390), 처음부터 |
| 화면 | 실제 크기(100%). 앱 화면은 390 기기 틀, 웹 진입 화면은 창 폭에 따라 모바일 웹 · 데스크톱 구성 |
| 화면 설명 패널 | 케이스별 설명. 번호는 화면 위 분홍 번호와 같습니다. 알림 케이스는 기기 상태(기기 알림 · OS 허용 창 · 국가 코드)를 바꿔 볼 수 있습니다 |

주소 끝에 케이스 ID를 붙이면 그 케이스로 바로 열립니다. 예: `/#DV-P02-b`, 상태값이 있는 케이스는 `/#DV-P04-a@1.00`

화면 안 버튼을 누르면 실제 흐름처럼 이어집니다 (투표 → 확정 → 결과 대기 + 출석 팝업, 알림 받기, 적립금 수령 등). 시간은 케이스마다 정한 시각에서 실제로 흘러가고, 표시는 기기 시간대를 따릅니다.

## 작업 순서

```bash
npm install
npx playwright install chromium   # 처음 한 번 (점검용 브라우저)
npm run check                      # 빌드 + 전 케이스 점검
```

- 케이스 · 설명 문구 수정: `src/cases.js` (+ `src/cases.en.js`)
- 화면 수정: `src/proto.html` (Tailwind 클래스 그대로 사용, 빌드 시 CSS 생성)
- 점검 결과가 `전체 N건 통과`일 때만 push 합니다

## 배포 (Vercel)

- 설정: `vercel.json` (Build `npm run build`, Output `dist`)
- `main`에 push하면 자동 배포
- 공개 범위: 링크가 있으면 누구나 볼 수 있음
